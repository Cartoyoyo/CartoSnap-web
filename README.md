# CartoSnap — version web

Site compilé de **CartoSnap** (appareil photo de terrain, coordonnées Lambert 93), publié sur GitHub Pages pour une utilisation sur iPhone via Safari.

**Ouvrir :** https://cartoyoyo.github.io/CartoSnap-web/

Sur iPhone : Safari → Partager → « Sur l'écran d'accueil », pour l'utiliser comme une appli et éviter que Safari efface les photos.

Ce dépôt ne contient que le résultat de `flutter build web`. Le code source est privé.
